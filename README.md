# كشف المتابعة الإلكتروني

تطبيق ويب لرصد درجات المشاركة والواجبات والمهام الأدائية والمشاريع لكل طالب في
كل شعبة، مع تصنيف تلقائي، لوحة تحليل أداء (Chart.js)، أرشيف إحالات مع تقارير
PDF، استيراد/تصدير Excel، ولوحة توقيع.

ملف HTML واحد (Vanilla JS، بدون أي framework) — نفس منطق وتصميم الأداة
الأصلية بالكامل، لكن بتخزين سحابي عبر [Supabase](https://supabase.com) بدل
`localStorage`، حتى لا تُفقد البيانات بتغيير الجهاز أو المتصفح.

## الحساب والبيانات

- يستخدم **نفس مشروع Supabase** المستخدم في تطبيق «معين» — لتوحيد حسابات
  المعلمين (تسجيل دخول واحد يوصل المعلم لكلا التطبيقين).
- جدول بيانات مستقل تمامًا خاص بهذا التطبيق فقط: `rasd_data` (لا يُخلط مع
  جداول معين). صف واحد لكل معلم يحوي كامل رصده كـ JSON، محمي بـ Row Level
  Security بحيث كل معلم يرى بياناته هو فقط.
- تصدير/استيراد JSON لا يزال متاحًا كنسخة احتياطية إضافية فوق التخزين
  السحابي (وليس بديلاً عنه).

## إعداد قاعدة البيانات (مرة واحدة)

1. افتح لوحة تحكم Supabase → **SQL Editor** → **New query**.
2. الصق محتوى [`supabase/migration.sql`](supabase/migration.sql) ونفّذه.

هذا ينشئ جدول `rasd_data` وسياسات RLS اللازمة، ولا يمسّ أي جدول من جداول
تطبيق معين.

## الاستضافة

منشور عبر GitHub Pages من فرع `main` (الجذر). الملف مكتفٍ ذاتيًا بالكامل؛
كل المكتبات (Supabase JS، xlsx، html2canvas، jsPDF، Chart.js) تُحمَّل من CDN.

## التطوير محليًا

افتح `index.html` مباشرة من جهازك (`file://`) للمعاينة السريعة — يتخطى
التطبيق شاشة تسجيل الدخول في هذا الوضع تلقائيًا، لكن أي تعديل لن يُحفظ
(لا يوجد حساب سحابي في وضع المعاينة المحلي).
